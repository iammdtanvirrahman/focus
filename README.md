# Focus — Modern Education Website

Mobile-first Bengali landing page for the Focus education brand.

## What's included
- Responsive homepage for desktop and Android/mobile
- Mobile navigation menu
- Courses section for university, medical, and engineering admission programs
- Why Focus and preparation steps sections
- Contact CTA linking to the current Focus website
- Bengali typography, accessible navigation labels, reduced-motion support, and responsive layouts
- No build process required: open `index.html` directly or serve it as static HTML

## Preview locally
Open `index.html` in a browser.

## Deploy
GitHub Pages can host this static site:
1. Open the repository Settings → Pages.
2. Select the `main` branch and `/(root)`.
3. Save and wait for the Pages deployment to finish.

## Important
This is a front-end starter/prototype. Course information, enrollment, login, student results, payments, and administration are not connected to a live backend yet. Replace illustrative copy and UI metrics with verified Focus information before public launch.
